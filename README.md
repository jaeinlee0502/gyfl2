# g·class · 고양외고 수업 도구

Node.js 22 이상에서 외부 패키지 없이 실행합니다.

```sh
cd /workspace/gyfl2
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. 개발 중에는 `npm run dev`를 사용하세요. 서버가 실행된 상태에서 `npm test`로 실제 통합·게임 규칙·보고서 테스트 11개를 실행합니다. 다른 서버 주소는 `TEST_URL`로 지정합니다.

## 도구

- 발표자 뽑기: 번호/특징, 결석 번호 제외, 중복 추첨 방지
- 실시간 투표: 최대 10개 선택지, 두 선택지 밸런스 게임, 결과 막대 그래프
- 워드클라우드: 선택적 길이 제한, 반복 단어 크기 반영
- 타이머: 프리셋, 직접 입력, 일시 정지, 종료 알림, 전체 화면
- 룰렛: 직접 입력한 명단, 회전 애니메이션, 당첨자 제외
- 논쟁 배틀: 자유 댓글 → 첫 찬반 선택 → 재토론 → 최종 진영 선택, 하트 공감, 말풍선·점수판·보고서

활동 생성 후 학생에게 6자리 코드 또는 참여 링크·QR을 공유하세요. 학생은 같은 서버의 사이트에 접속해야 합니다. QR은 UTF-8 기준 106바이트까지의 참여 주소를 지원하며, 더 긴 주소는 링크로 공유하세요. 교사 제어 토큰은 현재 탭의 sessionStorage에 저장되며 새로고침 후 활동을 이어갈 수 있습니다. 결과 CSV를 내려받을 수 있습니다.

## 데이터와 운영 범위

방과 응답은 `.data/rooms.json`에 저장됩니다. 이 폴더는 Git에서 제외합니다. 브라우저별 참여 식별자로 활동당 1회 응답을 허용하며, 다른 브라우저를 이용한 재참여까지 막는 인증은 없습니다. 학생 실명은 수집하지 않습니다. 교사 계정/학교 인증, QR 이외의 외부 서비스 연동, 성적부는 포함하지 않습니다.

실제 학교에서 접속하려면 이 Node 서버를 HTTPS가 지원되는 호스팅에 별도 배포하고 지속 저장소를 연결해야 합니다. 현재 구현은 단일 서버용으로, 여러 서버 인스턴스가 같은 파일을 동시에 쓰는 운영은 지원하지 않습니다. 학생 응답은 1.6초 간격으로 갱신합니다. 응답 데이터의 보관·삭제는 운영자가 관리해야 합니다.

현재 작업은 게시나 배포를 수행하지 않습니다.

## 게임형 논쟁 배틀

새 방은 소속 없이 시작하는 진행 방식입니다. 기존 팀 자동 배정 방식으로 만들어 둔 방은 당시 순서와 결과를 유지합니다. 새 순서를 쓰려면 새 방을 만드세요.

1. 선생님이 논제와 두 입장을 정해 방을 만듭니다.
2. 학생이 QR/참여 링크로 접속해 참가 버튼을 누릅니다. 처음에는 전원 소속 없이 가운데에 모입니다. 최대 100명이며 시작 후 신규 입장은 관전만 가능합니다.
3. ‘자유 댓글 시작’을 누르면 5분 동안 자유롭게 의견을 씁니다. 이때는 찬성·반대에 배정되지 않습니다. 댓글은 ‘1. 자유 댓글’ 목록에 쌓이고 캐릭터 말풍선에도 표시됩니다.
4. ‘첫 찬반 선택 시작’을 누르면 각 학생이 자기 입장을 1회 선택합니다. 선택한 사람만 해당 진영으로 이동하며, 자동 배정하지 않습니다. 화면에서 찬반별 인원과 선택 완료 인원을 확인할 수 있습니다. 모두 선택하면 ‘재토론 시작’을 누릅니다.
5. 재토론은 5분입니다. ‘3. 재토론 댓글’에 찬반별로 새 댓글이 쌓입니다. 이전 자유 댓글은 접힌 보관 영역에 남으며 펼쳐 읽을 수 있습니다. 재토론 중에는 말풍선에 재토론 댓글만 표시해 이전 의견과 혼동되지 않게 합니다.
6. ‘최종 진영 선택 시작’을 누르면 각 학생은 기존 입장을 유지하거나 반대편으로 옮길 입장을 1회 선택합니다.
7. ‘경기 종료’로 승패와 최종 선택 인원을 확인합니다. 동점은 무승부이며 미선택 인원은 별도로 표시됩니다.
8. 종료 화면의 ‘같은 논제로 처음부터 다시 시작’은 같은 논제·입장의 새 방을 만들며 새 참여 코드/QR을 공유해야 합니다. 원래 방과 결과는 덮어쓰지 않으며 브라우저 뒤로가기로 이전 결과에 돌아갈 수 있습니다. ‘모든 도구로 돌아가기’와 ‘새 논제로 토론 만들기’는 화면 하단에 있습니다.

하트는 자유 댓글·첫 찬반 선택·재토론 중에 선생님과 참가 학생이 누르고 취소할 수 있습니다. 같은 팀/반대 팀 구분 없이 다른 참가자의 댓글에 공감합니다. 자기 댓글에는 공감할 수 없고 관전자는 공감할 수 없습니다. 5분 작성 시간이 지나거나 최종 선택·종료 단계에서는 공감을 마감하고 버튼의 설명에 이유를 표시합니다. 선생님 공감도 방당 한 번만 집계되며, 토큰은 요청 헤더 또는 본문으로 보내고 참여 링크나 공개 결과에 넣지 않습니다.

두 작성 단계는 각각 5분입니다. 시간이 끝나면 댓글·공감 입력을 서버와 화면에서 막으며, 선생님이 다음 단계를 시작합니다. 시간이 남았어도 바로 넘길 수 있습니다. 학생은 경기당 최대 20개, 댓글당 300자까지 쓸 수 있습니다. 작성 중인 초안은 실시간 갱신과 하트 클릭으로 사라지지 않습니다.

점수: 첫 댓글 10P, 받은 공감 5P, 첫 찬반 선택 20P, 최종 선택 10P, 상대 팀에서 설득해 이동한 학생당 추가 30P. 자유 댓글의 점수는 작성자가 처음 선택한 팀에 반영됩니다. 중복 댓글은 기본 점수를 추가하지 않습니다. 실명 대신 참가 순번을 사용하며 학생 식별은 브라우저 기반이므로 다른 브라우저를 통한 재참가를 인증으로 차단하지는 않습니다.

결과 저장은 ‘결과 보고서 보기 / 저장’ → 미리보기 → ‘보고서 내려받기 (.html)’입니다. 파일에는 논제, 팀별 점수, 첫 찬반 선택과 최종 선택 인원, 참가자 번호별 전체 댓글과 공감 수가 담깁니다. 보고서에서도 자유 댓글과 재토론 댓글을 구분합니다. 저장 파일은 외부 이미지·폰트·스크립트 의존 없이 오프라인에서 읽을 수 있습니다. ‘인쇄 / PDF로 저장’을 누르고 브라우저 인쇄 창에서 PDF를 선택할 수도 있습니다. 진행 중 보고서는 ‘중간 결과’로 표시됩니다.

## 외부 수업 퀴즈

‘독버섯 맞추기 퀴즈’는 지락실닷컴 https://www.jiraksil.com/view/hz6brs 의 원본 퀴즈를 새 탭에서 여는 도구입니다. 문항 수(5~50/전체 112), 제한 시간, 일반/출제 모드를 선택합니다. 원본이 제공하는 실행 URL로 연결하며 문제·이미지·정답을 복제하거나 우리 서버에서 수집하지 않습니다. 출제 모드는 제한 시간을 적용하지 않습니다. 결과는 우리 서버에 저장되지 않습니다. 원본의 URL이나 동작이 바뀌면 연결을 확인해야 합니다.

추가 연결 퀴즈: 동물 이름 맞추기(899865), 세계사 상식(m8gpd5), 종합 상식(qbyy7k), 대학생 수준의 역사 상식(774qhn), 문해력 테스트(능력 고사, vwc7v5), 아재개그(7f685s), 고등학교 수준의 과학 상식(zbbcwp). 모두 같은 설정 화면을 공유하며 각 원본의 문항 수와 코드로 연결합니다.

대한민국 근현대사 퀴즈: 역사적 사건과 인물 맞추기(8qfj5t, 50문항)도 같은 외부 퀴즈 도구로 연결합니다.
